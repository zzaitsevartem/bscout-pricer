Luna нашла несколько дополнительных возможностей упростить проект.
- Poetry — в backend/pyproject.toml остались метаданные и зависимости Poetry, а README содержит команды poetry install/run. Текущий процесс установки использует pip. Перед удалением метаданных нужно проверить, поддерживается ли отдельно установка через pip install ..
- Диалоговые окна — три компонента повторяют открытие и закрытие dialog, блокировку прокрутки и восстановление фокуса. Эту логику можно собрать в общий hook.
- Ошибки API — одинаковая функция извлечения сообщения об ошибке есть в трёх местах frontend. Её можно вынести в общую библиотеку.
- Парсеры Profi и TGSM — ещё три небольшие функции обработки HTML совпадают. Их можно объединить, сохранив обработку пробелов, ссылок и хлебных крошек.
- Парсеры Liberti и Divizion — одинаковый цикл разбора списка товаров можно перенести в общий BitrixParser, предварительно проверив остальные его наследники.
- Prettier используется для форматирования и находится в runtime-зависимостях. Его можно перенести в devDependencies.
- Документация — DESIGN.md всё ещё упоминает удалённую зависимость class-variance-authority, а в MASTERPLAN.md осталось устаревшее утверждение о tenacity.пше
