## Исправление и live восстановление

- Причина: `extract()` fuzzy-сопоставлял токен `xperia` с односоставным alias `xperiaz` по edit distance 1. `Xperia C` отсутствовал в справочнике, поэтому C2304 получал `device_model_key=sony-xperia-z`. Добавлены Xperia C (C2304) и aliases `xperia c`, `sony xperia c`, `c2304`; fuzzy device теперь отклоняет совпадение, когда короткий токен — строгий префикс alias. Approve повторно извлекает модель и отдаёт 409, если она отличается от device выбранного продукта, либо если старый fuzzy-device кандидат уже нельзя подтвердить по текущему справочнику.
- Рабочая БД восстановлена одной транзакцией только для offer IDs **100904** (`product 50 → 9459`, manual/.765 сохранены) и **101955** (`product 223 → 9460`, auto/.900 сохранены). Для них созданы device `sony-xperia-c-c2304`, aliases, cluster и продукты black/unknown и white/category_1. Прежний и новый cluster aggregates пересчитаны. Offer active, category_id NULL, store, цена и остальные поля сохранены.
- Кандидат **765** сохранён в статусе `approved` как запись исходного решения; текущее соответствие оффера исправлено.
