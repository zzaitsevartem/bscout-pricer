## 1. Rate limit

Инвентаризированы **95 API operations** через актуальный OpenAPI; `.unlazy/develop-one/routes.json` содержит method/path/security schema и фактические бюджеты. Исходная статическая инвентаризация `routes.txt`. OpenAPI security schema не различает обязательную и optional-auth зависимость; авторизация по-прежнему проверяется существующими backend deps. Все API операции проверены тестом на бюджет; health освобождён явно.

- Общий бюджет 120/60s, verified access JWT → user ID, иначе IP. Credentials 10/300s по IP; search 90/60s; write 30/60s; export/admin mutations/import/parser/broadcast 10/60s; webhook отдельные 600/60s. Refresh/logout/username-available не расходуют строгий credential budget.
- Redis Lua атомарно проверяет/добавляет элемент sliding window; общий namespace, TTL, хеширование identity. Отвергнутый запрос не продлевает окно. Бюджет четырёх независимых процессов проверен на настоящем отдельном Redis.
- Redis timeout 1s. Read/refresh/logout fail-open, credentials/write/expensive/webhook fail-closed 503+Retry-After. Webhook получает временную ошибку для повторной доставки провайдером; его payment integrity не изменялась. Background workers не расходуют HTTP budget, существующие lock/full-sync guards сохранены.
- XFF принимается только от явно доверенного peer CIDR, справа налево. nginx заменяет входной XFF. Uvicorn сохраняет настоящий peer; отдельный TrustedProxyMiddleware принимает X-Forwarded-Proto http/https только от доверенного peer, сохраняя HTTPS redirects. Production EDGE_SUBNET и trusted CIDR согласованы. Перед реальным deploy проверить свободный CIDR и пересоздать старую edge-сеть при необходимости; deployment здесь не тестировался.

Файлы: `backend/src/middleware/{rate_limit,client_ip}.py`, `backend/src/main.py`, config, auth controllers, nginx/compose/Dockerfile и только `.env.example` templates. Полная политика `.unlazy/develop-one/rate-limit-policy.md`.
