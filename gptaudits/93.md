| Находка | Исправление |
|---|---|

| Оба парсера повторяли обработку отсутствующей и некорректной цены | Общая функция safe_price делегирует разбор parse_price и возвращает None при ошибке парсера. Добавлены тесты граничных случаев. |
| Backend объявлял tenacity без использования | Удалена прямая зависимость из requirements.txt и pyproject.toml. |
| Пять frontend-сервисов повторяли проверку ответа по Zod-схеме | createContractChecker сохраняет имя модуля и источника в предупреждении, пропускает проверку в production. Добавлен unit-тест. |
| Шесть прямых npm-зависимостей не использовались | Удалены три пакета Radix UI (navigation-menu, slot, visually-hidden), class-variance-authority, embla-carousel-react и lucide-react. Обновлены package-lock.json и README. |

Первоначальная проверка дала 497 успешных backend unit-тестов, 754 интеграционных на изолированных PostgreSQL и Redis и 228 frontend-тестов в 43 файлах. Выборка из 84 тестов парсеров входит в 497. Прошли Ruff, pip check, чистый npm ci, frontend lint, production build, TypeScript и Prettier для изменённых файлов. Общий format:check отметил 69 файлов базового состояния.
