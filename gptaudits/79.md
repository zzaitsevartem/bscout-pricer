# Исследование GreenSpark — 2026-11-15

Создана ветка bscout/greenspark-parser-2026-11-15; пользовательские незакоммиченные изменения сохранены. Luna исследовала сайт и близкие парсеры, но из её окружения DNS не разрешился. Из основного окружения curl к robots.txt вернул HTTP 200 с HTML JavaScript-проверки, а не robots.txt. В обычном встроенном браузере после ожидания открылись главная и карточка товара с регионом Ставрополь: артикул GS-00009455, розница 1100 ₽, оптовый тариф 770 ₽, наличие «Мало» на момент проверки. Это не доказательство доступа из автономного Docker worker, полноты каталога или стабильности сессии. Ветка не содержит реализации парсера; регистрация и работающие обходы не менялись. Дальнейшая задача: получить разрешённый стабильный машинный доступ или выгрузку, проверить регион и структуру каталога, затем реализовать и проверить парсер без записи в рабочую БД при разработке.

Повторная проверка: обычный Playwright Chromium внутри текущего worker открыл главную и показал Ставрополь; после загрузки стартовой страницы context.request получил robots.txt и sitemap.xml. Однако конкретная карточка GS-00009455 вернула HTTP 403 и через context.request, и при обычной навигации браузера в том же контейнере. Та же карточка открывалась в пользовательском встроенном браузере. Следовательно, доступ к главной и sitemap не доказывает работающий доступ worker к товарам. Защита не обходилась, парсер не зарегистрирован; нужен легитимный доступ от магазина или выяснение причины ограничения для рабочего окружения.

Дополнительная проверка по просьбе пользователя: через обычный headless Chromium в Docker worker главная GreenSpark теперь тоже ответила страницей 403; одновременно новый in-app браузер показал ту же страницу 403 на главной. DNS внутри worker разрешался, прямой HTTP вернул HTML с кодом 200, но ранее он был страницей проверки. Нет оснований утверждать причину блокировки, постоянство или различие IP. Рабочий парсер не реализован; текущие задачи и данные не менялись.
